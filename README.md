# ICLR 2027 虚拟细胞投稿图谱

在线浏览：https://mxqmxqmxq.github.io/iclr2027-virtual-cell-atlas/

ICLR 2027 投稿中与**虚拟细胞、单细胞扰动预测、靶点发现**相关的 169 篇论文的整理：分类、横向对比、六条主线（证伪潮、生成式分布建模、先验知识的真实价值、机制化虚拟细胞、LLM 与智能体、从预测到决策）、研究空白，以及一个可检索、可筛选的论文库。

## 数据与方法

- **来源**：OpenReview API（`ICLR.cc/2027/Conference/-/Submission`），2026-10-11 抓取，共 43,013 条投稿。
- **筛选**：关键词初筛得到 470 篇候选，再按标题和摘要逐篇判断，保留 169 篇。
- **标注**：由 AI（Claude）逐篇阅读摘要做结构化标注，包括主类别、扰动类型、任务、数据模态、方法、先验知识、主要结果、该文指出的问题，以及中文短标题和大白话说明。
- **独立核对**：由未参与标注的 AI 检查者逐篇对照英文摘要核对全部 169 篇，共发现 323 处需要修正，已全部采纳。

## 局限

- 只基于标题、关键词和摘要，没有阅读全文。
- 都是评审中的匿名投稿，结论可能在讨论阶段修改，录用情况未知。本页是 2026-10-11 的快照，不随评审结果自动更新。
- 关键词筛选可能漏掉用其他术语描述的同类工作。
- 中文短标题与说明为意译，可能仍有错误，引用请以 OpenReview 原文为准。
- "该文指出的问题"只记录论文摘要自己对现有做法的批评，不代表本页的评价。

论文摘要的版权归原作者，本页只作索引与综述。
